AI Gateway

Route every AI action across your own model providers. Set keys for Google Gemini, OpenAI and Anthropic Claude, choose a primary and fallbacks, and control which model handles which task — so you optimise quality and cost.

🔒 Keys are AES-GCM encrypted on-device in this preview
⚠ Security: In production, provider keys live only in the server-side gateway and are never sent to the browser. This preview stores them encrypted locally so you can configure routing — use restricted/test keys here, not production secrets.
