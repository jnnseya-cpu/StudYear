AI Gateway

Route every AI action across your own model providers. Set keys for Google Gemini, OpenAI and Anthropic Claude, choose a primary and fallbacks, and control which model handles which task — so you optimise quality and cost.

🔒 Keys are AES-GCM encrypted on-device in this preview
⚠ Security: In production, provider keys live only in the server-side gateway and are never sent to the browser. This preview stores them encrypted locally so you can configure routing — use restricted/test keys here, not production secrets.

🧭 Routing

Which provider runs by default, and the fallback order if one is unavailable.
Example: diagnostics & quick explanations → a fast/cheap model; marking, lesson planning & predictions → your primary.

⚡ Turn the AI tools live (preview, this device)

Switch the student & staff AI tools (AI Tutor first) from on-device templates to a real model. The key is stored on this device only and called from the browser — use a restricted/test key. Google Gemini is the smoothest from a browser; OpenAI and Anthropic also work.

💳 Turn subscriptions live (Stripe Payment Links)

Paste one Stripe Payment Link per plan — one line each as planId https://buy.stripe.com/…. Subscribe buttons then redirect to real Stripe checkout with the buyer's promo code prefilled. Leave blank to keep preview activation. No server needed; a Firebase/Vercel Checkout-Session server can replace this later.
